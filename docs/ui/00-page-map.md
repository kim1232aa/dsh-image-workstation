## 跨页一致（【必须】）

- 比例顺序：自动、1:1、3:4、4:3、9:16、16:9、2:3、3:2、21:9
- 清晰度：自动 / 1K / 2K / 4K
- 张数：1 / 2 / 3 / 4
- 图动作：下载、加画廊、加对话、当参考图、重新生成、复制提示词、拿去做视频
- 视频动作：播放、下载、加画廊、抽帧、重新生成
- 视频 URL：原样，不改域名
- 加载：进度 + 耗时 + 取消；出错：原因 + 重试
- 无审查 / 无评分锁出图 / 无低分强制确认
