## 7. 反推提示词

**入口：** 生图工具条 /「更多」

### 组件

```
ReversePrompt
├─ 上传图片（本地 · 拖拽 · 粘贴 · 历史/画廊/结果卡一键）
├─ 视觉模型选择
├─ 追加指令（可选，如「只描述构图和光线，不要描述内容」）
├─ 流式结果区（边推边显示）
└─ 动作：复制 · 一键填进提示词框
```

### 标签

上传图片、视觉模型、追加指令、复制、填进提示词框

### 要点

- **流式返回**，勿等整段蹦出
- 结果可复制、可一键回填生图提示词框

## 8. GIF 生成

**入口：** 生图工具条 /「更多」

### 组件

```
GifStudio
├─ 提示词（动作或变化过程）
├─ 帧数
├─ 帧序列预览（单帧重新生成 · 删帧 · 调顺序）
├─ 帧率 · 循环次数 · 尺寸
├─ 本地编码成 GIF
└─ 导出 GIF · 加画廊
```

### 标签

帧数、帧率、循环次数、尺寸、单帧重新生成、删帧、调顺序、导出 GIF、加画廊

### 要点

- 多帧保持一致性；**本地编码**，不依赖上游
- 帧序列与成品 GIF 都保存

## 9. Agent 对话生图

**入口：** 右栏「AI 对话」+ dsh 会话

### 组件

```
AgentImageChat
├─ 对话线程（图内联）
├─ 斜杠命令改图（不经对话模型）
├─ 模型确认（多模型时【必须】先问用哪个）
└─ 设置：「允许 Agent 调用生图」（可关；关后工作台页不受影响）
```

### 标签

AI 对话、允许 Agent 调用生图、加画廊、当参考图

### 要点

- 「画一只猫」直接出图；续说改图以上一张为参考，无需重传全描述
- Agent 可看图、可联网搜索
- 未配渠道 → 明确引导去设置，不静默失败
- 多模型时先问，不擅自选

## 10. UI 设计模式

**入口：** 生图工具入口（宽屏）

### 组件

```
UiDesignMode
├─ 上传设计稿
├─ AI 切图提议 →【必须】确认框勾选后才切（失败自动重试一次）
├─ 切图编辑器
│  ├─ 缩放 · 平移 · 拖拽新建切片 · 框选 · 8 向缩放 · 每角圆角 · 吸附
│  ├─ 右键 · 快捷键
│  ├─ 撤销重做（【必须】≥50 步）
│  └─ 三视图：原图（带框线）| 抠图结果 | 只看切片（棋盘底）
├─ 素材处理（各自独立可撤销，互不覆盖）
│  ├─ 算法抠透明 · AI 抠透明
│  ├─ 算法转 SVG · AI 重绘 SVG
│  └─ 算法可批量；【必须】AI 一次只跑一个
├─ 背景填充（范围框 · 移除区 · 本地合成版 / AI 原图版）
├─ 网页复刻（多轮 agent → index.html / styles.css / script.js + 只读 assets/）
│  ├─ 按行编辑 · iframe 预览 · 上下文用量警告
└─ 导出：切片包 ZIP · 完整设计包；可从包还原工作区
```

### 标签

AI 切图、确认、原图、抠图结果、只看切片、算法抠透明、AI 抠透明、算法转 SVG、AI 重绘 SVG、本地合成版、AI 原图版、导出

### 要点

- 带遮罩 edits 仅列支持 OpenAI `/images/edits` 的模型
- 勾选确认后才真切，不自动存

## 11. 模板库 / 提示词广场

**入口：** 生图区「模板库」+ 空状态灵感案例

### 组件

```
TemplateLibrary
├─ 案例卡片（示例图）
├─ 分类筛选 · 关键词搜索 · 收藏筛选
├─ 来源切换（多来源独立）
├─ 详情：完整提示词 · 参考图 · 作者署名 · 原链接
└─ 一键回填提示词框 · 收藏 · 在线更新 · 缓存离线浏览
```

### 标签

模板库、提示词广场、灵感案例、随机、收藏、一键回填

### 要点

- 点灵感卡填提示词；「随机」换一批（空状态）
