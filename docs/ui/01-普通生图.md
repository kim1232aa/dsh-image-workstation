# 普通生图 · 三栏规格

顶栏当前选中：普通生图

```
┌─────────────┬──────────────────────────┬─────────────┐
│ 历史记录     │ 生图区                    │ AI 对话      │
│ （左）       │ （中）                    │ （右·默收起） │
└─────────────┴──────────────────────────┴─────────────┘
```

- 对话默认收起；顶栏按钮展开
- 三栏可拖宽，宽度记忆

## 关键流

1. **普通出图**：填提示词 → 调参数 → 开始生成 → 结果区进度 → 并排结果 → 动作条
2. **图生图**：切图生图 → 参考图（上传/拖/贴/一键）→ 同 1
3. **回填**：点历史项 → 参数全回填（含模式与参考）
4. **Skill（可选）**：选入口 → 写想法 → 想方案 → 改方案 → 就这样出图 / 重新想一版  
   - 比例/负面词按 skill 预填，用户可改  
   - 评分只提示，默认焦点在「就这样出图」  
   - 参考图默认仅分析；要图生图则切模式
5. **空状态**：点灵感卡填提示词；随机换一批
6. **生成中**：不挡操作，可改参数准备下一次、可切顶栏
