# 画廊 / 素材库 · 规格

顶栏当前选中：画廊

满意作品长期沉淀；与图/视频共用入库来源。

```
┌──────────────┬────────────────────────────┐
│ 筛选侧栏      │ 瀑布流 / 规整网格            │
│ （数量统计）   │ （最新 / 最早）              │
└──────────────┴────────────────────────────┘
```

空状态：说明怎么把图加进来。

---

## 组件树

```
GalleryPage
├─ FilterRail
│  ├─ 模式（含视频）
│  ├─ 模型
│  ├─ 比例
│  ├─ 自建标签（新建 · 改 · 删）
│  └─ 数量统计
├─ Toolbar
│  ├─ 视图：瀑布流 | 规整网格
│  ├─ 排序：最新 | 最早
│  └─ 批量：打标签 · 下载
├─ MediaGrid
│  └─ GalleryCard（图或视频缩略）
└─ Lightbox
   ├─ 大图/视频预览
   └─ Actions：当参考图 · 加对话 · 拿去做视频 · 加入画布 · 下载 · 删标签等
```

入库入口（跨页）：结果卡 · 全屏预览 · 历史记录 ·「加画廊」

---

## 关键流

1. **加入**：任意结果/历史 →「加画廊」；同内容去重，不重复入库
2. **浏览**：左筛（模式/模型/比例/标签+数量）→ 右瀑布流或网格 → 最新/最早
3. **标签**：新建/改/删；多选批量打标签；批量下载
4. **预览**：点开大图/视频 → 当参考图 / 加对话 / 拿去做视频 / 加入画布 / 下载
5. **性能**：图多虚拟滚动或分页，滚得动
