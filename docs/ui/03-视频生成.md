# 视频生成 · 规格

顶栏当前选中：视频生成（与普通生图 / 无限画布平级）

共用：同一套任务队列、历史记录、画廊、存储、渠道配置。协议内置，不做插件包。

```
┌─────────────┬──────────────────────────┐
│ 历史记录     │ 视频生图区                │
│ （左·与图共用）│ （中）                    │
└─────────────┴──────────────────────────┘
```

历史与普通生图共用一条列表（按模式可筛到视频项）；也可独立左栏同组件复用。

```
│  │  └─ 尾帧图（可选）
│  ├─ RefSlots（渠道支持才显示）
│  │  ├─ 参考图
│  │  ├─ 参考视频
│  │  └─ 参考音频
│  ├─ ParamRow
│  │  ├─ 时长
│  │  ├─ 清晰度（自动/1K/2K/4K；或渠道分档：标准/高清/超清，价差标清）
│  │  ├─ 比例（9 项固定序）
│  │  └─ 模型
│  ├─ CTA：开始生成
│  ├─ ResultArea
│  │  ├─ Progress（进度 · 耗时 · 取消） / 失败（原因 · 重试）
│  │  ├─ VideoPlayer（播放 · 进度条）
│  │  ├─ Meta（时长 · 分辨率 · 模型）
│  │  └─ ResultActions（下载 · 加画廊 · 抽帧 · 重新生成）

└─ （无强制右栏；可复用 AI 对话收起态）
```

## 状态字段

```
mode: 'txt2video' | 'img2video'
prompt: string
firstFrame?: ImageRef
lastFrame?: ImageRef
refImage?: ImageRef       // 渠道支持
refVideo?: VideoRef
refAudio?: AudioRef
duration: number | string // 渠道档位
clarity: 'auto'|'1K'|'2K'|'4K' | ChannelClarityTier
ratio: 'auto'|'1:1'|'3:4'|'4:3'|'9:16'|'16:9'|'2:3'|'3:2'|'21:9'
modelId: string
task?: { id, status, progress, elapsedMs, error?, resultUrl? }
// resultUrl：上游原样，不做域名改写
results: VideoResultCard[]  // 含 duration, resolution, modelId
historyFilter / history：与图共用
```

## 关键流

1. **文生视频**：提示词 → 时长/清晰度/比例/模型 → 开始生成 → 异步进度 → 播放结果
2. **图生视频**：切图生视频 → 首帧（必）/ 尾帧（可选）→ 同 1；参考图/视频/音频按渠道露出
3. **拿去做视频**：普通生图结果或画廊图 → 跳转本页并填入首帧
4. **异步**：提交拿 task_id → 轮询；可见进度与耗时；可取消（真停）；失败给原因 + 重试（参数保留）
5. **结果**：播放（进度条）→ 下载 / 加画廊 / 抽帧（帧可当参考图或加入画布）/ 重新生成
6. **URL**：上游返回什么用什么，不改写域名、不代理转发
7. **生成中**：不挡操作，可切顶栏、可改参数准备下一次
8. **历史/画廊/队列**：与图同一套；关页再开未完成任务仍在

## 与画布打通

- 画布图片节点可连到视频生成配置节点
- 抽帧结果可「加入画布」

---

## 不做

- 视频插件包 / 插件套插件
- 生图页内「视频开关」把视频降级为附属
- URL 域名改写
- 内容审查 / 评分锁 CTA
- Cordis / 协议代码（本规格止于 IA）
