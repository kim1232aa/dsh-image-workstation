# 电商套图 · 规格

顶栏当前选中：电商模式

一张商品图扩成一整套。**【必须】** 先计划预览，确认后再批量生成。

```
┌────────────────────┬─────────────────────────┐
│ 上传与配置           │ 套图预览 / 结果           │
│                    │ 主图左大 · 其余右纵排      │
└────────────────────┴─────────────────────────┘
```

空状态：说明要传什么图。

---

## 组件树

```
EcommercePage
├─ UploadBlock
│  ├─ 商品主图（最多 4：主体 / 包装 / 细节）
│  └─ 风格参考图（可选 1 张）
├─ ProductForm
│  ├─ 商品名称
│  ├─ 参数信息（可「AI 帮写」）
│  └─ 文案语言（中英日韩等 · 可自定义）
├─ PurposePicker
│  └─ 用途勾选 + 每种张数：
│     主图 · 卖点图 · 场景图 · 细节图 · 规格图 · 使用图
│     （每种可单独指定参考图）
├─ PlanPreview：「套图预览」（只看计划，不烧额度）
│  └─ 确认批量生成（显示预计张数 N）
├─ ResultLayout
│  ├─ 主图（左 · 大）
│  └─ 其余用途（右 · 纵排）
│     └─ 单张动作：重新生成 · 下载 · 加画廊 · 加对话
├─ Export：「导出清单」（提示词+参数）
└─ HistoryFold：整组折叠为一条；点开恢复继续编辑
```

## 状态字段

```
productImages: ImageRef[]     // ≤4：主体/包装/细节
styleRef?: ImageRef
name: string
paramsText: string
locale: string                // 中/英/日/韩/自定义
purposes: {
  id: 'hero'|'selling'|'scene'|'detail'|'spec'|'usage'
  enabled: boolean
  count: number
  refImageId?: string
}[]
plan?: PlanSheet              // 预览态
confirmed: boolean
taskBatch?: { total, done, items[] }
results: { purposeId, images[] }
historyGroupId?: string       // 历史折叠一条
```

## 关键流

1. 上传主图（≤4）+ 可选风格参考
2. 填名称/参数（可 AI 帮写）· 选文案语言
3. 勾选用途与张数；可每用途指定参考图
4. 「套图预览」只看计划 → 确认「要生成 N 张」→ 批量跑
5. 先生主图，其余以主图为参考，保证同品
6. 结果：主图左大，其余右纵排；单张可重生成/下载/加画廊/加对话
7. 导出清单；历史整组折叠一条，点开续编
8. 生成中不挡操作（批量确认除外）
