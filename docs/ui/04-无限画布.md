# 无限画布 · 规格

顶栏当前选中：无限画布

节点式自由编排；**【必须】** 画布上同时处理图片节点与视频节点。

```
┌──────────────────────────────────────────────┐
│ 项目条：项目名 · 新建 · 重命名 · 列表切换          │
├──────────────────────────────────────────────┤
│                                              │
│              无限画布视口                       │
│   （节点 · 连线 · 框选）                        │
│                                              │
│  ┌小地图┐                          [适应全部]  │
└──┴──────┴────────────────────────────────────┘
         ┌─ 底部生成器（选中配置节点时浮出）─┐
```

空状态：自带一组文本 + 配置节点，开箱能用。

## 组件树

```
CanvasPage
├─ ProjectBar
│  ├─ 项目名 / 重命名
│  ├─ 新建项目
│  └─ 项目列表切换
├─ CanvasViewport
│  ├─ Nodes
│  │  ├─ ImageNode（图；可来自本地拖入 / 粘贴 / 历史·画廊「加入画布」）
│  │  │  └─ NodeTools：标注 · 移除背景 · 指定模型
│  │  ├─ VideoNode（视频；可播放；可抽帧落图节点）
│  │  ├─ TextNode（文本 → 连配置 = 提示词）
│  │  └─ GenConfigNode（生成配置）
│  ├─ Edges（两侧圆点拖拽连线）
│  ├─ Selection（框选多选）
│  ├─ MiniMap（左下）
│  └─ FitAll：「适应全部内容」
├─ BottomGenerator（选中 GenConfigNode 时浮出）
│  ├─ PromptInput
│  ├─ 模型 · 比例 · 张数（及清晰度等与生图一致项）
│  └─ 发送 → 结果落右侧并保持连线
└─ ContextMenu（右键）
```

## 中文标签（照抄）

| 区域 | 标签 |
|---|---|
| 节点类型 | 图片节点、文本节点、生成配置节点；视频节点 |
| 连线语义 | 文本→配置＝提示词；图片→配置＝参考图（第一张＝图生图底图） |
| 节点工具 | 标注、移除背景、指定模型 |
| 画布操作 | 适应全部内容 |
| 项目 | 新建、重命名 |
| 生成器 | 发送 |
| 跨页 | 加入画布（历史/画廊） |
| 标注说明 | 框选一块 + 写提示词；只改框内；红框不进成品 |

## 关键流

1. **开箱**：空画布带文本 + 配置节点 → 写提示词 → 发送出图 → 结果图落右侧并连线
2. **迭代**：结果再连下一配置节点，一路迭代
3. **参考**：图片连配置＝参考图；多张时第一张当图生图底图
4. **标注**：图片节点 → 标注 → 框选 + 提示词 → 只改框内
5. **移除背景 / 指定模型**：节点级操作
6. **跨页加入**：历史或画廊 →「加入画布」
7. **视频**：视频节点可播；可连生成；抽帧 → 新图片节点
8. **项目**：多项目保存；新建 / 重命名 / 切换
9. **导航**：小地图；「适应全部内容」回正
