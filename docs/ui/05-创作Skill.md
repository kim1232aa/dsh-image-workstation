# 创作 Skill · 规格

落点：普通生图区 **可选入口**（非必经）。不选 = 普通生图。

权威规则在本地 skill 目录（运行时读取，不硬编码）。产品权威 00–03；本页不设作者门禁、不锁 CTA。

## 组件树

```
SkillEntry（生图区可选）
├─ SkillPicker：电影三联 | 三联封面 | 电影海报 | 人像 | 摄影 | 角色
├─ IdeaInput（大白话想法）
├─ CTA：「想方案」
├─ PlanView（可编辑）
│  ├─ 判断块（大白话：矛盾 / 观众站位 / 视线 / 颜色 / 镜头变化…）
│  ├─ 每张图提示词（可改）
│  ├─ 比例（预填可改）
│  ├─ 负面词（自动带上 · 可见 · 可删）
│  └─ 其他参数（张数等）
├─ SelfCheck（有打分表的 skill）
│  ├─ 总分 · 各项 · 低项白话说明
│  └─ 「就这样出图」（默认焦点）|「重新想一版」
│      ※ 分数永不禁用、不弹窗拦截、不自动重试
└─ Generate：「出图」
```

人像子项：升级已有照片 | 原创人像  
角色附加：三视图（勾选才出）

海报分层结果：底图层 | 字体层 | 合成图 | 记录；按钮「只重出字体层」

## 关键流

```
写一句想法 → 想方案 → 看方案 → 想改就改 → 出图
                              ↓
                        不满意 → 重新想一版
```

1. 选入口（可选）→ 写想法 →「想方案」
2. 方案摊开：判断（人话）+ 提示词/比例/负面词
3. 任意部分可改；改判断可提示「要不要重新生成提示词」
4. 有自检：显示分数；**默认焦点「就这样出图」**；「重新想一版」另钮
5. 「出图」：比例/张数/负面词按方案落实；三联本地纵向拼（黑间隔约 10px）；海报分层
6. 方案可存、可复用；出图失败不必重想
7. 参考图默认仅分析；要图生图则切图生图模式

## 参数落实

| 项 | 行为 |
|---|---|
| 比例 | skill 预填（三联 21:9、海报 9:16、封面 3:4）；**界面显示且用户可改** |
| 张数 | 三联＝3 |
| 负面词 | 自动带上；界面可见可删 |
| 拼接 | 本地纵向；间隔 8–12px（取 10）；无文字/序号/水印/边框/圆角/阴影 |
| 参考图 | skill 模式默认只分析 |
